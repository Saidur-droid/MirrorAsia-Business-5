# First 90 Days

## Day 1–15 — Foundation

Choose:
**FMCG beverages/snacks.**

Tasks:
- recruit/partner for first respondent sample,
- define consent/privacy framework,
- build population schema,
- collect 10 historical research cases if possible,
- interview 10 insights/brand professionals.

## Day 16–30 — Population v0

Create:
- demographic distribution,
- language profile,
- purchase behavior,
- category attitudes,
- media/channel behavior,
- price sensitivity,
- household variables.

Build first synthetic population.

## Day 31–45 — Blind benchmark

Use historical studies with known outcomes.

Run MirrorAsia blind.

Measure:
- winning-concept rank agreement,
- preference error,
- price direction,
- segment disagreement.

Do not manually tune to known answers before testing.

## Day 46–60 — Calibration

Analyze failure:
- which segment,
- which category,
- which task,
- which language,
- which model prompt/config.

Recalibrate.

Version population:
BD-FMCG-v0.2.

## Day 61–75 — Design partners

Get 2–3:
- FMCG brand,
- agency,
- consumer startup.

Run real upcoming concepts.

Always show confidence.

## Day 76–90 — Human validation

For selected simulations:
run real human checks.

Create first real benchmark report.

Commercial goal:
at least one paying pilot or clear annual-contract intent.

## Day-90 success test

Continue aggressively if:
- simulation ranking shows meaningful agreement,
- customers save time,
- human validation improves model,
- buyers want repeated usage,
- benchmark quality improves.

Rework if:
- results are unstable,
- customers do not trust outputs,
- all studies require full human research,
- local data access is too weak.

## Day-90 artifacts

- benchmark report,
- MirrorScore methodology,
- panel/data policy,
- design-partner case,
- live demo,
- pricing hypothesis,
- investor memo only if evidence exists.
