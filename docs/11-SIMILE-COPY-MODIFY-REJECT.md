# Simile → MirrorAsia: Copy / Modify / Reject

This is the most important strategic comparison document.

"Copy" here means **copy the public business pattern/principle**, not code, brand, proprietary data, private methods or IP.

---

| Simile pattern | MirrorAsia decision | Why |
|---|---|---|
| Start populations from real people | **COPY** | Generic demographic prompting is not defensible |
| Continuous real-human validation | **COPY** | Accuracy/trust is the company |
| Confidence attached to simulations | **COPY** | Avoid fake certainty |
| Combine observed behavior + interviews/surveys | **COPY** | Need both "what" and "why" |
| Customer can bring own data | **COPY** | Enables enterprise-specific population |
| Sell decisions, not AI personas | **COPY** | Stronger economic buyer/value story |
| Start with enterprise-critical workflows | **COPY** | High willingness to pay |
| Use customer case studies to prove value | **COPY** | Trust-heavy category needs evidence |
| Expand from simple populations to dynamic/multi-agent systems | **COPY LATER** | Powerful roadmap after core accuracy |
| Research + engineering + product + operations team | **COPY AT SMALL SCALE** | Correct functional team shape |
| Global population ambition | **MODIFY** | We should win Bangladesh/one category first |
| Foundation model from scratch | **MODIFY** | Too capital-intensive initially; use existing models + local fine-tuning/evaluation |
| Huge daily global data collection | **MODIFY** | Start with partner panels + targeted Bangladesh datasets |
| Broad use cases: policy, litigation, earnings calls, etc. | **REJECT FOR V1** | Too broad, trust/risk burden too high |
| "Simulate 8 billion people" early mission | **REJECT AS INITIAL OPERATING GOAL** | Distracts from local PMF |
| Raise huge rounds before local proof | **REJECT** | MirrorAsia needs benchmark + paying customers first |
| Copy Simile pricing | **REJECT** | Public pricing is not available and BD economics differ |
| Claim Simile-level accuracy | **REJECT** | Must earn our own benchmark |
| Treat synthetic users as a total replacement for human research | **REJECT** | Human validation is core to our model |
| Individual-level sensitive prediction/persuasion | **REJECT** | Privacy, trust and misuse risk |

# What we copy most aggressively

## 1. Validation-first company design

This is not an optional research department.

MirrorAsia's product must be built around:

- blind backtests,
- held-out human evidence,
- segment-level error,
- confidence,
- continuous refresh.

## 2. Enterprise land-and-expand

MirrorAsia should first prove one painful decision workflow.

Example:

FMCG concept/price/packaging exploration.

Then expand inside the same account:

concept test  
→ ad/message  
→ customer journey  
→ competitor simulation  
→ category/market simulation.

## 3. Custom population with customer data

Base Bangladesh population is the platform.

Large customer data becomes:

base Bangladesh population  
+ customer first-party data  
+ customer research  
+ real outcome feedback  
= client-specific model.

## 4. Case-study GTM

Do not scale ads before evidence.

First flagship cases should show:

- traditional timeline,
- MirrorAsia timeline,
- number of concepts tested,
- human benchmark result,
- known errors,
- what decision changed.

# What we intentionally do differently

## Bangladesh as calibration laboratory

Simile starts globally ambitious.

MirrorAsia starts locally deep.

We need to know:

- Bangla/Banglish,
- Dhaka vs other regions,
- income/household structure,
- mobile commerce,
- Facebook/social commerce,
- bKash/Nagad behavior,
- family influence,
- Ramadan/Eid seasonality,
- local price sensitivity.

## FMCG-first

We choose one repeatable, benchmarkable commercial wedge.

This is our capital-efficient way to earn trust.

## Human Check inside the workflow

Instead of positioning human research as old technology, we integrate it.

Simulation explores widely.

Human research validates where confidence or stakes demand it.

## MirrorScore

Simile has its own confidence/evaluation approach.

MirrorAsia creates a customer-visible category/segment benchmark score so local buyers understand exactly when to trust us.

# Final rule

When a future AI or founder asks:

> "Should we copy this Simile feature?"

Answer in this order:

1. Does it improve calibration?
2. Does it improve enterprise decision value?
3. Does it create proprietary local data?
4. Can we support it with our current Bangladesh evidence?
5. Can we measure whether it works?

If not, do not copy it yet.
