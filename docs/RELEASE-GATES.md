# Launch gates

## Gate A: code
- [ ] Reproducible lockfile committed; CI uses npm ci
- [ ] CI unit tests, typecheck and Next.js production build pass
- [ ] Dependency audit triaged for critical/high vulnerabilities
- [ ] Security review: public API abuse limits, secret handling, logging, XSS
- [ ] Browser smoke test: scenario creation, API errors, mobile, health

## Gate B: demonstration
- [ ] Deploy on confirmed free-only hosting, project-selected workspace
- [ ] No paid model API key; MIRRORASIA_AI_MODE=preview
- [ ] No respondent DB and no storage of identifiable personal information
- [ ] No fabricated MirrorScore, accuracy, revenue or panel size
- [ ] Honest provenance available to reviewers

## Gate C: research
- [ ] Consent/withdrawal workflow approved before recruiting humans
- [ ] Train/holdout separation and per-segment validation
- [ ] Benchmarked model, not an uncalibrated demo
- [ ] Report error and coverage, including inconclusive cases

## Public demo limitation
Showing a working app and illustrative experimental simulation is legitimate
only when clearly labeled; it is not proof of real-world prediction accuracy.
